# CASE 01. 돌아오지 말았어야 할 사람

_The Man Who Should Never Have Returned_

> 아버지는 20년 전 그 아이를 죽였다고 자백했다. 아들은 어제 그 아이를 죽였다고 자백했다. 적어도 하나는 거짓이다. 어쩌면 둘 다.

- 상태: 팀 검토용 초안. 개발자 전용 스포일러 포함.
- 장르: 2D 픽셀 심리 미스터리·사회 추리.
- 핵심 소재: 허위 자백, 신분 사칭, 잘못된 믿음, 가족, 죄책감.
- 배경: 1990년대풍 가상 세계의 산골 마을 무연리, 늦가을.
- 핵심 NPC 4명, 현재 사망자 1명. 예상 플레이 시간 40~60분(미검증).
- 핵심 질문: 당신이 좋아하게 된 사람이 범인이라면, 그래도 진실을 밝힐 수 있는가?

## 핵심 결론 (스포일러)

20년 전 한지우는 살아서 마을을 떠났고 강문식은 허위 자백했다. 현재 죽은 사람은 지우를 사칭한 박윤재다. 이재현이 실제 한지우이며 윤하린이 윤재의 죽음에 책임이 있다. 강도현은 재현을 보호하려 허위 자백한다.

## 검토 필요

과거 수사와 신분 변경의 개연성, 피해자의 동기, 결정적 물증의 내용과 입증력, 증거 획득 조건 및 판정 조합을 팀에서 승인해야 한다. 현재 문서의 보완안은 확정 사실로 간주하지 않는다.
