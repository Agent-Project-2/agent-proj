# CASE 01 — 수사 및 판정

개발자 전용 초안. E01~E16은 설계 식별자이며 실제 계약 필드명은 미정이다. 아래 획득 조건은 논리 검토를 위한 신규 제안이며 구현·승인된 기능이 아니다.

## 증거 목록

| ID | 증거 | 입증 범위 | 기본 획득 / 대체 경로 |
| --- | --- | --- | --- |
| E01 | 도현의 자백서 | 18시경 자신이 살해했다는 주장 | 시작 시 공개 수사 기록 |
| E02 | 사망 조사 기록 | 사망 추정 시간 및 부상 경위 | 현장 조사 후 공개 기록 |
| E03 | 재현의 출입증 | 재현의 현장 방문 정황 | 현장 조사 |
| E04 | 19시 통화 기록 및 상대 진술 | 19시 피해자 생존 | 공개 수사 기록 요청, 통화 상대는 문서로 등장 |
| E05 | 진료소 업무 기록 | 사망 추정 시간대 재현의 알리바이 | 진료소 기록 조사 또는 공식 수사 자료 요청 |
| E06 | 윤재의 신분 서류 | 실제 이름 박윤재 | 현장 소지품 및 기록관 대조 |
| E07 | 과거 실종 사건 수사 기록 | 강문식 자백과 기록의 모순 | 기록관 조사 |
| E08 | 윤미정의 편지 | 지우의 생존 이탈 및 강문식의 도움 | 하린의 자발적 제공 또는 보관 자료 공식 조회 |
| E09 | 재현의 출생·보호 기록 | 이재현과 한지우의 동일인 여부 | 재현의 공개 또는 기록관의 적법한 수사 조회 |
| E10 | 윤재의 협박 편지 | 하린과의 만남 및 동기 | 현장 문서 또는 하린의 제공 |
| E11 | 휴대용 녹음기 | 마지막 대화 및 충돌 정황 | 사건 현장 조사 |
| E12 | 추가 감식 기록 | 녹음과 실제 사망 유발 행동의 교차 검증 | 현장 조사 후 공개 기록 요청 |
| E13 | 서윤의 20년간 편지 | 동생에 대한 감정·기억 | 개인 대화로 자발적 공유 |
| E14 | 강문식이 도현에게 남긴 편지 | 부자 관계·자백 배경 | 도현의 자발적 공유 |
| E15 | 하린의 어린 시절 진술서 | 과거 거짓 증언의 내용 | 기록관 또는 하린의 공개 |
| E16 | 재현의 어린 시절 물건 | 신원 보조 단서 | 재현의 자발적 공유 |

필수 단서는 친밀도와 무관한 접근 경로를 마련한다. 사생활 자료의 공식 조회는 게임 내 권한 검증을 전제로 한다. 보조 단서를 놓쳐도 사건 해결 가능. 증언과 물증, 추론은 구별한다.

## 추론의 근거

- E01 + E02 + E04: 도현이 주장한 시각과 실제 생존 기록 불일치. 이것만으로 도현의 모든 범행 가능성을 배제하지는 않는다.
- E04 + E05 + E02: 재현의 선행 다툼 이후 생존과 사망 추정 시간대 알리바이. 선행 부상과 사망의 인과관계는 감식에서 확인해야 한다.
- E06: 사망자의 신분. 신분 서류만으로 충분한지 기록 대조 방식 확정 필요.
- E08 + E09 (+ E07): 지우 생존과 과거 강문식의 무고를 확인.
- E10: 하린의 동기와 만남 정황. 단독으로 유죄를 입증하지 않는다.
- E11 + E12: 하린의 실제 사망 유발 행동과 부상의 인과관계를 입증할 조합으로 설계할 예정. 구체적인 내용·감식 기준이 미확정이므로 현재 충분한 증거로 검증되었다고 간주하지 않는다.

## 비선형 진행

| 경로 | 예시 |
| --- | --- |
| 물증 중심 | 현장 감식 → 자백의 모순 → 알리바이 → 마지막 만남 증거 |
| 관계 중심 | 도현과 자유 대화 → 자백 이유 → 재현 설득 → 관련 비밀과 물증 교차 검증 |
| 과거 중심 | 실종 수사 기록 → 사칭 확인 → 재현 신원 → 협박 동기 추적 |
| 대립 중심 | 증언 전달 → NPC 관계 및 믿음 변화 → 새로운 모순 확인 → 물증 |

반전 순서와 NPC의 협조 여부는 달라질 수 있지만 정답은 고정된다. 증거가 소실되거나 진행이 영구 차단되지 않도록 한다.

## 최종 추리

| 항목 | 정답 | 검증 근거 예시 |
| --- | --- | --- |
| 현재 사건 책임자 | 윤하린 | E11, E12 및 동기 보조 E10 |
| 사망자의 정체 | 박윤재 | E06 |
| 과거 사건 | 한지우가 살아서 떠남 | E08, E09 |
| 도현의 자백 이유 | 이재현 보호 | 도현의 확인된 공개 진술 또는 대체 근거 (추가 설계 필요) |
| 실제 한지우 | 이재현 | E08, E09 |
| 사망 경위·동기 | 하린과 윤재의 갈등 중 사망, 협박과 관계 상실에 대한 두려움 | E10~E12, 세부 검증 필요 |

판정기는 확보한 증거와 추론별 연결을 검사한다. 단순 이름 맞히기는 성공으로 보지 않는다. 복수의 유효 근거 조합을 허용한다. 기존 대화에서 제시한 체크박스 판정 UI는 개념 예시이며 확정 규칙이 아니다. 실제 사망 경위 및 자백 동기의 대체 근거가 미확정이므로 True End의 최종 판정 계약은 팀 검토 이후 확정한다.

## 엔딩

| 엔딩 | 조건 개념 | 서사 |
| --- | --- | --- |
| TRUE — 아무도 죽지 않았던 날 | 현재 및 과거의 진실과 충분한 근거 | 강문식 재심 절차 검토, 도현 자백 철회, 남매의 재회, 하린 책임 |
| NORMAL — 해결되었으나 끝나지 않은 사건 | 현재 사건 입증, 과거 미해결 | 도현의 결백, 부친 누명과 재현 신원은 남음 |
| BAD — 아버지와 아들 | 도현을 범인으로 보고 잘못 종결 | 과거 비극의 반복 |
| INCOMPLETE — 증명하지 못한 진실 | 근거 부족 또는 잘못된 추리 | 사건 미해결 |

BAD는 잘못된 보고의 서사적 결과이며 서버가 허위 추리를 올바른 판정으로 인정하는 것이 아니다.

## 관계 기반 에필로그 (추가 목표)

- 도현: 높은 신뢰·친밀감에서 마을 밖 수리점의 꿈을 이야기한다. “나중에 고장 난 물건 있으면 찾아오십시오. 그땐 조사관님이라고 할인해 드리진 않을 겁니다.”
- 서윤: 존중과 신뢰가 높다면 동생에게 편지를 건넨 뒤 기다릴 수 있게 된 마음을 이야기한다. “이번에는 기다리는 동안 살아 있다는 걸 알고 있으니까.”
- 하린: 애정을 유지하면서 책임을 물은 플레이어에게 “끝까지 제 편을 들어 주지 않아서 고마워요. 조금은.”
- 재현: 정체성을 존중받았다면 현재 이름으로 살겠다는 선택을 공유한다. “그 이름으로 만난 사람들이 있으니까요. 당신도 그중 한 사람입니다.”

에필로그는 실제 기억·관계·판정 결과를 참조하고 미확인 진실을 공개하지 않는다. 관계는 객관적 판정을 변경하지 않는다.
