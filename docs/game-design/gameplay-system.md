# 공통 게임 시스템 설계

팀 검토용 초안. 기존 PRD·기술 요구사항·공통 계약을 대체하지 않는다.

## 플레이 흐름

사건 선택 → 세션 생성 → 마을 탐색 → 장소 조사 및 NPC 자유 대화·심문 → 증거 제시·수첩 갱신 → 최종 추리 제출 → 판정·엔딩. 사건별 데이터만 교체하고 세션 및 NPC 엔진은 재사용한다. 동일한 초기 상태에서 다른 수사 방법을 시연할 수 있어야 한다.

## 장소와 그래픽

CASE 01의 제안은 마을 광장, 구 마을 사무소, 수리점, 기록관, 카페, 진료소다. 구 사무소는 실제 내부 탐색 맵, 나머지는 외관과 대화·조사 화면으로 간소화할 수 있다. 기존 MVP 장소 3곳과 충돌할 수 있으므로 물리적 탐색 장소는 광장·사건 현장·공용 조사 공간으로 통합하는 대안을 검토한다. 팀 승인 전 장소 수를 확정하지 않는다. 그래픽은 2D 픽셀 아트, 늦가을의 어두운 색조로 제안한다.

## 대화 UI

NPC 이름·직업·초상화·현재 태도, 대화 기록, 자유 입력, 전송 버튼을 제공한다. 일상 이야기·사건·다른 주민·증거 제시의 추천 질문은 선택적인 보조 수단이다. 확보한 증거는 목록에서 실제 ID로 선택한다. 로딩·오류·재시도 상태를 표시하며 중복 전송을 방지한다. 신뢰도 숫자 대신 자연스러운 태도 표현을 우선 검토한다. 일상 대화는 강제하지 않으며 대화 횟수만으로 필수 단서를 잠그지 않는다.

## 추리 수첩

| 탭 | 내용 |
| --- | --- |
| 인물 | 공개 프로필, 확인된 관계 및 공개된 비밀 |
| 증거 | 획득한 물증·문서 |
| 증언 | NPC의 주장 및 출처 |
| 시간표 | 확보한 기록의 사건 시각과 행적 |
| 모순 | 공개 자료 사이의 충돌 및 근거 |
| 개인 메모 | 플레이어 가설 |

물증, 미검증 증언, 추론 및 소문을 분리해 표시한다. 자동 모순 탐지는 플레이어가 확보한 기록만 사용하며 비공개 정답을 알려주지 않는다.

## 최종 판정과 엔딩

범인·방법·동기와 사건별 추가 질문을 불변 정의와 비교한다. 추론별 근거를 획득한 증거에서 선택하게 한다. 복수의 유효 조합을 허용하고 단순 범인 맞히기, 미획득 증거, 관련 없는 근거 제출은 성공으로 인정하지 않는다. 판정은 서버 규칙으로 수행하고 LLM은 설명·에필로그 문구 생성에만 사용한다. 잘못된 종결, 근거 부족, 현재 사건만 해결, 전체 해결 등의 엔딩을 사건별로 정의한다. 관계 기반 개별 에필로그는 추가 목표이며 실제 기억과 관계를 반영한다.

## 세션 및 기술 연동

게임 서버가 사건 진실, 세션, 위치, 시간, 획득 증거, 공개 기록, 행동 권한의 원본을 관리한다. NPC 로직은 프로필·기억·관계·믿음·소문 및 계획을 담당하며 공통 계약으로 연동한다. 세션 생성·저장·복원·초기화 시 NPC 동적 상태와 수사 상태의 일관성을 유지한다. 중요한 이벤트에만 LLM을 호출하고 규칙 기반 일상 이동과 분리한다.

처리 순서: 행동 요청 → 서버 검증·이벤트 기록 → NPC 허용 문맥 조회 → Skills 적용·LLM 판단 → MCP 조회/행동 요청 → 서버 재검증 → 상태·공개 기록·화면 반영. 중복 요청은 이벤트 ID로 제어한다. NPC와 클라이언트에는 접근 가능한 데이터만 전달한다.

## MCP 및 Skills (명칭 예시)

| 영역 | 예시 도구 |
| --- | --- |
| NPC 조회 | get_npc_context, recall_memory, get_relationship |

Skills 예시: npc-dialogue, memory-management, secret-management, interrogation-response, belief-revision, relationship-management, rumor-propagation, autonomous-decision, investigation-support. 초기에는 4~5개로 묶는 안을 검토한다. 실제 도구 등록 방식, 이름, 입출력은 #5 및 #14에서 공동 합의한다. 단순 함수 실행을 실제 MCP 검증으로 간주하지 않는다.

## 역할 및 범위

A: NPC 프로필·기억·비밀·자유 대화·심문 판단·믿음·관계·소문·자율 행동·NPC 도구·Skills·MCP 클라이언트. B: 이동·시간·세션·조사·공개 기록·수첩·대화 UI·픽셀 아트·판정·게임 도구 및 MCP 서버 기반. 공동: 사건·증거·초기 인물 설정·공통 계약·권한·통합 테스트. 기존 저장소 역할 및 이슈를 우선한다.

우선 구현 제안은 CASE 01, NPC 4명, 자유 대화와 심문, 기억 및 관계, 증거에 따른 믿음 수정, 소문, 제한된 자율 행동, 탐색·수첩·판정이다. CASE 02와 개별 에필로그는 추가 목표, 다자 실시간 대화 및 복잡한 일상 일정은 확장 후보다. 자유 일상 대화와 사건 2개는 팀 합의 후 공식 계획에 반영한다. 기존 내부 동결 12/13 및 제출 12/20 23:59 KST를 임의 변경하지 않는다.

## 테스트 및 시연

- 동일 초기 세션에서 공감·신뢰 중심과 압박·대립 중심의 수사 경로 비교.
- 일상 대화 기억이 후속 심문 또는 에필로그에 반영되는지 확인.
- 비공개 사실 누출, 잘못된 증거 ID, 중복 이벤트, 무한 소문 방지.
- 비협조 NPC가 있어도 필수 증거의 대체 획득 경로가 열려 있는지 확인.
- 잘못된 범인, 맞는 범인이나 부족한 증거, 현재 사건 해결, 전체 해결 판정 테스트.
- 세션 저장·복원과 초기화 테스트. Mock과 실제 LLM·MCP·Skills 검증은 구분.
- CASE 02 데이터 교체 시 공통 엔진 재사용 확인 (추가 목표).

현재 문서는 구현 명세의 초안이다. 실제 런타임, 호출 비용, 지연, 판정 조합 및 장소 범위는 검증되지 않았다.
